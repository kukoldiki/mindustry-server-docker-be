# Mindustry Server Docker (Bleeding Edge)
- Hi, this is a simple Docker image for a Mindustry **Bleeding Edge** (beta) server. I use it for my own servers.
- It tracks the latest builds from [Anuken/MindustryBuilds](https://github.com/Anuken/MindustryBuilds).
- Usage `docker pull ghcr.io/kukoldiki/mindustry-server-docker-be:latest`
- Or a specific build `docker pull ghcr.io/kukoldiki/mindustry-server-docker-be:27503`
